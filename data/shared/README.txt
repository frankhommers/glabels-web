This is the shared folder of gLabels Web.

- Put CSV or tab separated files here to use them as merge sources.
- Projects are saved here as .glabels files; you can open them from here too.
- Fonts (.ttf/.otf) belong in the "fonts" subfolder; they are usable in the
  editor and in prints right away.
- User product definitions live in the "templates" subfolder.

Everything stays inside this folder: the application never opens a file
outside it.
