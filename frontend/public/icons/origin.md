# Origin of these icons

These folders are taken from gLabels Qt (`glabels/icons/`), upstream commit
`554c9f04389f7a1afa18685cab015273f0b21d94`:
<https://github.com/j-evins/glabels-qt/tree/554c9f04389f7a1afa18685cab015273f0b21d94/glabels/icons>

gLabels is released under the GNU General Public License, version 3 or later.
This web app uses the icons to keep the interface recognisable for people who
know the desktop app. The same license applies when distributing; include the
matching copyright notice and license text.

See <https://github.com/j-evins/glabels-qt> and the `LICENSE` file there.

## Our own additions

`glabels-web/` holds icons we added or derived from the gLabels theme, in the
same visual language and under the same license. Every file says in a comment
where it comes from.

| File | Used for | Origin |
| --- | --- | --- |
| `folder.svg` | Every folder in the application | Redrawn after a design supplied by the client |
| `folder-full.svg` | *Files* in the page bar | "folder full" by Alfonso López-Sanz, see below |
| `glabels-data.svg` | Data files (CSV/TSV) in the file browser | Drawn for this project in the style of the gLabels theme |
| `glabels-template.svg` | Product definitions in the file browser | Drawn for this project in the style of the gLabels theme |
| `glabels-phone.svg` | *Open on phone* in the toolbar | Drawn for this project in the style of the gLabels theme |

## Attribution

`glabels-web/scalable/actions/folder-full.svg` is "folder full" by **Alfonso
López-Sanz**, via [The Noun Project](https://thenounproject.com/). The file
came with the attribution as text inside the drawing; that was taken out so
the icon is usable, which is why it is stated here and in the application's
About dialog. Otherwise only the fill colour was matched to the rest of the
page bar.

When distributing, check under which terms this icon was downloaded: icons
from The Noun Project are either CC BY (attribution required) or under a paid
license without that requirement.
